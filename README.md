# 🦔 刺蝟賽跑 racing-hedgehogs-game

改編自 Reiner Knizia 的桌遊《Racing Hedgehogs》（FoxMind）做成的網頁版。輪流打牌讓四色刺蝟往前跑，有一隻到終點這場就結束，大家用手上還沒出的牌算分。角色是摺耳貓戴刺蝟帽（SVG，貓的畫法沿用 croc-outfit-game）。

網站：https://kukocliao.github.io/racing-hedgehogs-game/

## 規則（照實體版，加上我們自己定的四點）

- 3–5 人。55 張牌：紅黃綠藍和彩虹萬用，每組走 1 步 6 張、跑 2 步 5 張。3 人發 15 張、4 人 13 張、5 人 11 張。
- 賽道：起點 → -1 ×7（最後一格在木橋上）→ 0（橋）→ 0 → 1 → 1 → 2 → 2 → 終點 3。
- 輪到你就打一張，同色刺蝟走 1 或 2 步；彩虹牌自己挑哪一隻走。
- 有刺蝟到終點就結算：讓牠到終點的人 +3，每個人手上剩的顏色牌照那隻刺蝟所在格計分，彩虹牌 0 分，這場總和是負的算 0。
- 場數＝人數，每場換左手邊（下一個座位）先出。總分最高贏，同分比最後一場。
- 我們定的：起點算 0 分；快到終點時「跑」超過也算到終點；同一格可以有好幾隻；用彩虹牌把刺蝟推到終點也拿 +3。

## 頁面

| 頁面 | 用途 |
|---|---|
| `host.html` | 大螢幕主控端：放賽道、輪到誰、分數；電腦玩家也在這裡跑。整局進行中這頁要一直開著 |
| `player.html` | 玩家手機：看自己的手牌、出牌 |
| `local.html?mode=pass` | 一台平板輪流傳：輪到誰先出現遮擋畫面，按了才看到自己的牌（本機，不連網） |
| `local.html?mode=group` | 一台電腦投影帶領：手牌公開，帶領者代點，有暫停（本機，不連網） |
| `guide.html` | 玩法說明＋開場介紹詞 |

真人不到 3 位時，電腦玩家自動補位。本機模式每出一張就存進瀏覽器，關掉再開可以「繼續上次那局」。

## 難度設定

| 預設 | 場數 | 出牌提醒 | 分數提示 | 字級 | 電腦玩家 |
|---|---|---|---|---|---|
| 長者 | 只打 1 場 | 不計時 | 牌上顯示現在值幾分 | 特大 | 隨便出（放水） |
| 兒童 | 場數＝人數 | 不計時 | 顯示 | 一般 | 隨便出 |
| 一般 | 場數＝人數 | 30 秒 | 不顯示 | 一般 | 會算分 |

出牌時間到只會提醒，不會替人出牌。手機版主持人可以按「幫他出一張」，給斷線的玩家用。

## Firebase 設定

沿用 `spot-the-difference-10a2b` 專案，房間路徑 `rooms/hedgehogs-main`，Authentication 要開「匿名」。

規則：Realtime Database → 規則 → 貼上 `database.rules.json` **全文** → 發布。這份檔案也包含 spot-the-difference、speed-colors、croc-outfit 三個舊房間的規則，**整份貼上才不會弄壞其他遊戲**。

## 安全設計

- 主控端第一次開啟時綁定 `hostUid`，完整局面（含所有手牌）存在 `secret`，只有主控端讀得到。重新整理會從這裡接回原局
- 公開的 `state` 只有每人手牌張數；`hands/{uid}` 只有本人和主控端讀得到
- 玩家出牌寫進 `move`：規則限定輪到的人（`state/turnUid`）、這一手（`state/t`）、只能寫一次、牌號 0–54、時間戳要等於伺服器時間。牌在不在手上由主控端判斷，不合法就退回
- 換裝置當主控端：到 Firebase 後台刪掉 `rooms/hedgehogs-main/hostUid`
